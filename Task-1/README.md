# Week 1 – ML & AI Submission

## Files
- `Week1_ML_AI_Assignment.ipynb` — complete Week 1 notebook.
- `requirements.txt` — required Python packages.
- `README.md` — setup and submission instructions.

## Dataset
Download the **Titanic Dataset** from Kaggle and place `Titanic-Dataset.csv` in this folder.

## Run
1. Install Python 3.
2. Open this folder in VS Code.
3. Open the notebook.
4. Select a Python/Jupyter kernel.
5. Run all cells from top to bottom.
6. Confirm that `titanic_cleaned.csv` is generated.
